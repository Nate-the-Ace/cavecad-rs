CAVWAY X1 · CONTROLS

Manual Rev. C · firmware 1.1.6

Buttons

DISTMeasure (top). Also powers on. MMenu / Enter · marks while laser on <Left · memory (newer) >Right · memory (older) CLRClear / back · hold = off

Power

  • On: press DIST. Off: hold CLR.
  • Lock + off: hold CLR + press >. Unlock: M within 2 s of turning on.
  • Sleeps after Idle time-off (60 s default, Options).

Shooting

  • DIST once = laser on; again = shot (beep).
  • Hold DIST 2 s = delayed shot.
  • Leg = 3 close shots in a row: double beep, LEG shows. Any other shot is a splay.
  • Mark (laser on): M cycles None → Feature → Ridge → Backsight → Generic.

Scan mode (sweeps)

  • Hold DIST+M 2 s (or >, set in Scan options): SCAN MODE.
  • Laser stays on; hold still a moment and it shoots by itself.
  • Ends: CLR, the time limit (default 2 min), or 200 shots.

Memory

< / > from measuring opens memory, newest on top. M = shot detail (4 pages: readings, errors, H/V, G/M/dip).

Menu (M)

  • Calibration · Clr. Unsent · Options · Information · Advan. Menu
  • Options: reference, delay, backlight, beep, idle off.
  • Information p.2: last calibration's errors and dip.
ACC ERR = the two sensor sets disagree. Move away from metal and magnets first (phone, watch, headlamp, batteries, steel, cars, rebar). Still frequent: recalibrate (overleaf).

With CaveCAD

  • Connect, pick CavwayX1-…; a sleeping X1 rejoins when woken.
  • Single shot / Station to station: press = laser on, press again = 1 or 3 shots.
  • Keep the phone 30 cm+ from the X1 while shooting.

Hold >: clears all "not sent" flags.

CALIBRATION · ACCURACY

Calibrate away from all metal, outdoors if possible

Calibrate

  1. Magnetically quiet spot: no steel, cars, rebar; phone, watch, headlamp, batteries well away.
  2. Turn on, M → Calibration.
  3. Rear of the X1 fixed at point A, laser on a target B 5 m+ away.
  4. DIST to shoot, roll the X1 90° about the laser, shoot again. 4 shots per group: double beep when complete.
  5. Choose a new direction and repeat. Cover all directions: level all round, steeply up, steeply down, in between.
  6. Both circles (up / down half) darken as covered; x done, + current. Fill both: 14+ groups (25 max).
  7. Bad shot in a group: > resets that group.
  8. 8+ groups: M computes; read the report per sensor set.
  9. M = apply, CLR = discard and keep shooting groups.

Good result

Rule of thumb: average error 0.3° or less (the manual's example: average 0.25°, max 1.28°). Much worse: discard, check for nearby metal, take more groups.

Tips

  • By hand is recommended; a jig must keep the dot still while rolling.
  • Firmware upgrades erase calibration: save coefficients first (Cavway Assistant).

CaveCAD's own check

Capture → Accuracy check: Strict (every X1 complaint), Normal (2 % G, 5 % M, 5° dip, 2° angle), Relaxed (×2).

Firmware boot mode

Off, USB to PC, hold <+> and press DIST; then Cavway Assistant → Firmware.
