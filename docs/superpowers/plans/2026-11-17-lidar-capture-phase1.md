# CaveCAD Capture, Phase 1 (app shell + one handheld shot) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A separate iPhone app, CaveCAD Capture, that signs in with the CaveCAD account, downloads a cave, lets the person pick a station and tap the forward station, records one handheld LiDAR shot, saves it as a versioned capture bundle on the phone, and shows it placed in survey coordinates.

**Architecture:** A pure Rust crate `cave-capture` (in the main workspace, wasm32-safe) owns the bundle format, station positions from a cave's ops, and the capture-to-survey placement math. A small Rust static library in `apps/capture-ios/rust` (its own workspace, like `apps/desktop`, because it needs `unsafe` for the C interface) exposes those to Swift. A SwiftUI app generated by XcodeGen does sign-in, cave download, ARKit capture and a SceneKit viewer.

**Tech Stack:** Rust 2024 (serde, serde_json), `cave-doc`, `cave-survey`, `cave-id`; Swift 6 / SwiftUI, ARKit (`sceneReconstruction = .mesh`), SceneKit, AuthenticationServices; XcodeGen; `cargo` targets `aarch64-apple-ios`, `aarch64-apple-ios-sim`.

**Spec:** `docs/superpowers/specs/2026-11-17-lidar-room-capture-design.md`. This plan is Build-order step 1 only. Steps 2–5 get their own plans after this one ships.

**User decisions (already made):**
- "CaveCAD Capture" is a **separate app** whose data integrates **directly** into CaveCAD on the app and the server.
- **Stop between shots**: each shot is its own ARKit session.
- **Every shot sits over a survey station**; heading comes from a crosshair tap on the forward station (no compass).
- First version reaches **walls on the map** (later plans).
- Nathan is non-technical and trusts the approach: architecture is decided here, only product questions go to him.

**Facts this plan relies on (checked 2026-11-17 on origin/main a089046):**
- Server caves are open JSON: snapshot `GET /api/caves/:id/snapshot` → `{"snapshot": {"upTo": n, "keyVersion": k, "locked": "<text>"}}` where `<text>` is `{"upTo": n, "ops": [...]}`; entries come from `GET /api/caves/:id/stream?after=n` as NDJSON lines `{"t":"entry","number":..,"locked":"<text>"}` with `<text>` = `{"c": client, "ops": [...]}`, then one `{"t":"live"}` line once caught up, then pings. Ops deserialize as `Vec<cave_doc::Op>`.
- Desktop sign-in: open `https://cavecad.com/signin?desktop=1&challenge=<base64url(sha256(verifier))>&state=<random>`; server ends at `cavecad://auth?code=..&state=..`; `POST /api/desktop-token {"code","verifier"}` → `{"token","expires_in"}`; later calls send `Authorization: Bearer <token>`. Native URLSession sends no `Origin`/`Sec-Fetch-Site`, so the cross-site guard passes. `ASWebAuthenticationSession` with callback scheme `cavecad` catches the redirect inside its own session, so it does not collide with the CaveCAD app's own `cavecad://` handler.
- `cave_survey::{extract, resolve}` place stations; `Placed.pos` is `cave_survey::Vec3 {x east, y north, z up}` metres; station names are `Field::StationLabel`. `cave_id::Id` is `Copy`, `Display`, `FromStr`.
- `cave_fixture::from_shot_list(text, ActorId(1))` builds a test cave.
- The gimbal work (`tools/cave-osmo`, 44 commits on `ble-bridge`) is **not on main**. Phase 1 does not need it. It must be merged before the Phase 2 plan.

```rust
//! The capture bundle (`.cvcap`): one shot as one file. Layout, little-endian:
//! `MAGIC`, `u16` format, `u32` header length, header JSON, then positions (`f32` × 3n), normals
//! (`f32` × 3n), indices (`u32` × 3m), then each keyframe's JPEG bytes in order. Counts and JPEG
//! lengths live in the header, so a reader never guesses.

use serde::{Deserialize, Serialize};

/// First bytes of every capture bundle.
pub const MAGIC: &[u8] = b"CVCAP\0";
/// The format this code writes. A reader refuses anything newer.
pub const FORMAT: u16 = 1;

/// A heading tap: the crosshair ray when the person tapped a station they could see.
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct HeadingTap {
    /// The station tapped (a `cave_id::Id` as text).
    pub target_station_id: String,
    /// Its label at the time, for people reading the file.
    pub target_label: String,
    /// Ray origin in the capture frame (ARKit world, metres, Y up).
    pub origin: [f64; 3],
    /// Ray direction in the capture frame (unit length).
    pub dir: [f64; 3],
}

/// Everything about a shot except its bulk arrays.
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct ShotHeader {
    /// This shot's id (random, made by the app).
    pub shot_id: String,
    /// The server cave it belongs to.
    pub cave_id: String,
    /// The station the rig stood over (a `cave_id::Id` as text).
    pub station_id: String,
    /// That station's label at the time.
    pub station_label: String,
    /// When it was captured (milliseconds since 1970, from the phone).
    pub captured_at_ms: i64,
    /// Phone model identifier.
    pub device: String,
    /// Height of the phone above the station mark, metres.
    pub instrument_height_m: f64,
    /// Camera position in the capture frame when the shot started.
    pub start_camera: [f64; 3],
    /// Heading taps, first one wins.
    pub taps: Vec<HeadingTap>,
    /// How tracking went: `normal`, `limited` or `lost`.
    pub tracking: String,
}

/// One kept camera frame, for colouring the mesh later.
#[derive(Clone, Debug, PartialEq)]
pub struct Keyframe {
    /// Camera-to-capture transform, column-major 4×4.
    pub pose: [f32; 16],
    /// Camera intrinsics, column-major 3×3.
    pub intrinsics: [f32; 9],
    /// Image width in pixels.
    pub width: u32,
    /// Image height in pixels.
    pub height: u32,
    /// The JPEG bytes.
    pub jpeg: Vec<u8>,
}

/// A whole shot: header, mesh in the capture frame, keyframes.
#[derive(Clone, Debug, PartialEq)]
pub struct Shot {
    /// The header.
    pub header: ShotHeader,
    /// Vertex positions, xyz per vertex.
    pub positions: Vec<f32>,
    /// Vertex normals, xyz per vertex.
    pub normals: Vec<f32>,
    /// Triangle vertex indices, three per triangle.
    pub indices: Vec<u32>,
    /// Kept camera frames.
    pub keyframes: Vec<Keyframe>,
}

/// Why bytes are not a usable shot.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum BundleError {
    /// The file does not start with [`MAGIC`].
    NotACapture,
    /// Written by a newer app (the format number).
    NewerFormat(u16),
    /// The file ends early.
    Truncated,
    /// The header is not readable.
    BadHeader,
    /// Mesh arrays disagree, an index points past the vertices, or a number is not finite.
    BadMesh,
}

#[derive(Serialize, Deserialize)]
struct Wire {
    header: ShotHeader,
    vertex_count: u32,
    triangle_count: u32,
    keyframes: Vec<WireKeyframe>,
}

#[derive(Serialize, Deserialize)]
struct WireKeyframe {
    pose: Vec<f32>,
    intrinsics: Vec<f32>,
    width: u32,
    height: u32,
    jpeg_len: u32,
}

/// Writes a shot as bundle bytes.
pub fn encode(shot: &Shot) -> Vec<u8> {
    let wire = Wire {
        header: shot.header.clone(),
        vertex_count: (shot.positions.len() / 3) as u32,
        triangle_count: (shot.indices.len() / 3) as u32,
        keyframes: shot
            .keyframes
            .iter()
            .map(|k| WireKeyframe {
                pose: k.pose.to_vec(),
                intrinsics: k.intrinsics.to_vec(),
                width: k.width,
                height: k.height,
                jpeg_len: k.jpeg.len() as u32,
            })
            .collect(),
    };
    let json = serde_json::to_vec(&wire).expect("header always serializes");
    let mut out = Vec::with_capacity(json.len() + shot.positions.len() * 8 + shot.indices.len() * 4);
    out.extend_from_slice(MAGIC);
    out.extend_from_slice(&FORMAT.to_le_bytes());
    out.extend_from_slice(&(json.len() as u32).to_le_bytes());
    out.extend_from_slice(&json);
    for v in shot.positions.iter().chain(&shot.normals) {
        out.extend_from_slice(&v.to_le_bytes());
    }
    for i in &shot.indices {
        out.extend_from_slice(&i.to_le_bytes());
    }
    for k in &shot.keyframes {
        out.extend_from_slice(&k.jpeg);
    }
    out
}

struct Reader<'a> {
    b: &'a [u8],
    at: usize,
}

impl<'a> Reader<'a> {
    fn take(&mut self, n: usize) -> Result<&'a [u8], BundleError> {
        let end = self.at.checked_add(n).ok_or(BundleError::Truncated)?;
        let s = self.b.get(self.at..end).ok_or(BundleError::Truncated)?;
        self.at = end;
        Ok(s)
    }
    fn u16(&mut self) -> Result<u16, BundleError> {
        Ok(u16::from_le_bytes(self.take(2)?.try_into().expect("2 bytes")))
    }
    fn u32(&mut self) -> Result<u32, BundleError> {
        Ok(u32::from_le_bytes(self.take(4)?.try_into().expect("4 bytes")))
    }
    fn f32s(&mut self, n: usize) -> Result<Vec<f32>, BundleError> {
        let raw = self.take(n.checked_mul(4).ok_or(BundleError::Truncated)?)?;
        Ok(raw.chunks_exact(4).map(|c| f32::from_le_bytes(c.try_into().expect("4 bytes"))).collect())
    }
    fn u32s(&mut self, n: usize) -> Result<Vec<u32>, BundleError> {
        let raw = self.take(n.checked_mul(4).ok_or(BundleError::Truncated)?)?;
        Ok(raw.chunks_exact(4).map(|c| u32::from_le_bytes(c.try_into().expect("4 bytes"))).collect())
    }
}

/// Reads bundle bytes back into a shot, checking everything a viewer or the matcher relies on.
pub fn decode(bytes: &[u8]) -> Result<Shot, BundleError> {
    if !bytes.starts_with(MAGIC) {
        return Err(BundleError::NotACapture);
    }
    let mut r = Reader { b: bytes, at: MAGIC.len() };
    let format = r.u16()?;
    if format > FORMAT {
        return Err(BundleError::NewerFormat(format));
    }
    let len = r.u32()? as usize;
    let wire: Wire = serde_json::from_slice(r.take(len)?).map_err(|_| BundleError::BadHeader)?;
    let n = wire.vertex_count as usize;
    let m = wire.triangle_count as usize;
    let positions = r.f32s(n * 3)?;
    let normals = r.f32s(n * 3)?;
    let indices = r.u32s(m * 3)?;
    let mut keyframes = Vec::with_capacity(wire.keyframes.len());
    for k in wire.keyframes {
        let pose: [f32; 16] = k.pose.try_into().map_err(|_| BundleError::BadHeader)?;
        let intrinsics: [f32; 9] = k.intrinsics.try_into().map_err(|_| BundleError::BadHeader)?;
        let jpeg = r.take(k.jpeg_len as usize)?.to_vec();
        keyframes.push(Keyframe { pose, intrinsics, width: k.width, height: k.height, jpeg });
    }
    if r.at != bytes.len() {
        return Err(BundleError::Truncated);
    }
    let finite = positions.iter().chain(&normals).all(|v| v.is_finite());
    let in_range = indices.iter().all(|&i| (i as usize) < n);
    if !finite || !in_range {
        return Err(BundleError::BadMesh);
    }
    Ok(Shot { header: wire.header, positions, normals, indices, keyframes })
}
```
Note: `truncated` passes because the last JPEG is cut short (`take` fails). Trailing bytes after a complete shot are also refused, as `Truncated` (the file does not end where it should).

```rust
//! Where a shot sits in the cave. ARKit's capture frame is metric, gravity-aligned, Y up, with an
//! arbitrary heading. The survey frame is x east, y north, z up. Gravity is shared, scale is never
//! changed, so placing a shot is one turn about the vertical plus a shift.

use cave_survey::Vec3;

/// A capture-frame point in survey axes (before any turn): `(x, -z, y)`.
pub fn capture_to_survey(p: [f64; 3]) -> Vec3 {
    Vec3 { x: p[0], y: -p[2], z: p[1] }
}

/// Compass bearing of a horizontal direction, degrees clockwise from north, in `0..360`.
pub fn bearing_deg(east: f64, north: f64) -> f64 {
    east.atan2(north).to_degrees().rem_euclid(360.0)
}

/// A shot's place in the survey: survey = turn(capture_to_survey(p − start)) + origin.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Placement {
    /// Clockwise turn applied to bearings, degrees.
    pub turn_deg: f64,
    /// Survey position of the shot's start camera.
    pub origin: Vec3,
    /// Capture-frame start camera position, taken off before turning.
    pub start: [f64; 3],
}

impl Placement {
    /// A capture-frame point in survey coordinates.
    pub fn apply(&self, p: [f64; 3]) -> Vec3 {
        let v = capture_to_survey([p[0] - self.start[0], p[1] - self.start[1], p[2] - self.start[2]]);
        let (s, c) = self.turn_deg.to_radians().sin_cos();
        Vec3 {
            x: v.x * c + v.y * s + self.origin.x,
            y: -v.x * s + v.y * c + self.origin.y,
            z: v.z + self.origin.z,
        }
    }
}

/// Places a shot from a heading tap: the tap ray (capture frame) pointed at `target`, the rig stood
/// over `station`, the phone `height_m` above the mark, the shot started with the camera at `start`.
/// `None` when the ray is within 2° of vertical (it has no bearing).
pub fn heading_from_tap(station: Vec3, target: Vec3, dir: [f64; 3], start: [f64; 3], height_m: f64) -> Option<Placement> {
    let d = capture_to_survey(dir);
    let horiz = (d.x * d.x + d.y * d.y).sqrt();
    let len = (horiz * horiz + d.z * d.z).sqrt();
    if len == 0.0 || horiz / len < 2f64.to_radians().sin() {
        return None;
    }
    let want = bearing_deg(target.x - station.x, target.y - station.y);
    let have = bearing_deg(d.x, d.y);
    Some(Placement {
        turn_deg: (want - have).rem_euclid(360.0),
        origin: Vec3 { x: station.x, y: station.y, z: station.z + height_m },
        start,
    })
}
```

```rust
use cave_doc::{ActorId, Document, Field, Op};
use cave_id::Id;
use cave_survey::{Vec3, extract, resolve};
use serde::Deserialize;

/// A placed station.
#[derive(Clone, Debug, PartialEq)]
pub struct StationSeed {
    /// Its id.
    pub id: Id,
    /// Its label.
    pub label: String,
    /// Survey position, metres (x east, y north, z up), unadjusted.
    pub pos: Vec3,
}

#[derive(Deserialize)]
struct Ops {
    ops: Vec<Op>,
}

/// Rebuilds a cave from the server's open snapshot text (`{"upTo":n,"ops":[...]}`, if any) and the
/// entry texts after it (`{"c":client,"ops":[...]}`), in number order. An op that does not fit is
/// skipped, as the app's own sync does.
pub fn document_from_room(snapshot: Option<&str>, entries: &[&str]) -> Result<Document, String> {
    let mut doc = Document::new(ActorId(1));
    let parts = snapshot.map(|s| ("snapshot".to_string(), s)).into_iter().chain(
        entries.iter().enumerate().map(|(i, e)| (format!("entry {}", i + 1), *e)),
    );
    for (name, text) in parts {
        let o: Ops = serde_json::from_str(text).map_err(|e| format!("{name} unreadable: {e}"))?;
        for op in &o.ops {
            let _ = doc.apply(op);
        }
    }
    Ok(doc)
}

/// Every station the survey places, in survey order.
pub fn stations(doc: &Document) -> Vec<StationSeed> {
    let ex = extract(doc);
    let r = resolve(&ex.legs, &ex.fixed);
    let mut placed: Vec<_> = r.stations.iter().collect();
    placed.sort_by_key(|(_, p)| p.seq);
    placed
        .into_iter()
        .map(|(id, p)| StationSeed {
            id: *id,
            label: doc.entity(*id).map(|e| e.text(Field::StationLabel)).unwrap_or_default(),
            pos: p.pos,
        })
        .collect()
}
```

```rust
//! C interface to `cave-capture` for the CaveCAD Capture iPhone app. Every function takes plain
//! pointers and returns a `CcBuf` the caller frees with `cc_free`. Inputs are never trusted: a
//! null or malformed argument gives an error JSON (or empty bytes), never a crash.
#![allow(unsafe_code)]

use cave_capture::{Keyframe, Shot, ShotHeader, decode, document_from_room, encode, heading_from_tap, stations};
use cave_survey::Vec3;
use serde::Deserialize;
use std::ffi::{CStr, c_char};

/// Bytes owned by Rust.
#[repr(C)]
pub struct CcBuf {
    /// Start.
    pub ptr: *mut u8,
    /// Length.
    pub len: usize,
}

fn give(v: Vec<u8>) -> CcBuf {
    let mut b = v.into_boxed_slice();
    let out = CcBuf { ptr: b.as_mut_ptr(), len: b.len() };
    std::mem::forget(b);
    out
}

fn give_json(v: serde_json::Value) -> CcBuf {
    give(v.to_string().into_bytes())
}

fn err(msg: &str) -> CcBuf {
    give_json(serde_json::json!({ "error": msg }))
}

unsafe fn text<'a>(p: *const c_char) -> Option<&'a str> {
    if p.is_null() { None } else { unsafe { CStr::from_ptr(p) }.to_str().ok() }
}

unsafe fn slice<'a, T>(p: *const T, n: usize) -> &'a [T] {
    if p.is_null() || n == 0 { &[] } else { unsafe { std::slice::from_raw_parts(p, n) } }
}

/// Releases a buffer returned by any `cc_` function.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn cc_free(buf: CcBuf) {
    if !buf.ptr.is_null() {
        drop(unsafe { Box::from_raw(std::ptr::slice_from_raw_parts_mut(buf.ptr, buf.len)) });
    }
}

/// See `capture_core.h`.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn cc_stations(snapshot: *const c_char, entries_json: *const c_char) -> CcBuf {
    let snap = unsafe { text(snapshot) };
    let entries: Vec<String> = match unsafe { text(entries_json) } {
        None => Vec::new(),
        Some(t) => match serde_json::from_str(t) {
            Ok(v) => v,
            Err(_) => return err("entries are not a JSON array of texts"),
        },
    };
    let refs: Vec<&str> = entries.iter().map(String::as_str).collect();
    match document_from_room(snap, &refs) {
        Err(e) => err(&e),
        Ok(doc) => give_json(serde_json::Value::Array(
            stations(&doc)
                .into_iter()
                .map(|s| serde_json::json!({ "id": s.id.to_string(), "label": s.label, "x": s.pos.x, "y": s.pos.y, "z": s.pos.z }))
                .collect(),
        )),
    }
}

#[derive(Deserialize)]
struct KeyIn {
    pose: Vec<f32>,
    intrinsics: Vec<f32>,
    width: u32,
    height: u32,
    jpeg_len: usize,
}

#[derive(Deserialize)]
struct HeaderIn {
    #[serde(flatten)]
    header: ShotHeader,
    keyframes: Vec<KeyIn>,
}

/// See `capture_core.h`.
#[unsafe(no_mangle)]
#[allow(clippy::too_many_arguments)]
pub unsafe extern "C" fn cc_shot_encode(
    header_json: *const c_char,
    positions: *const f32, n_positions: usize,
    normals: *const f32, n_normals: usize,
    indices: *const u32, n_indices: usize,
    jpegs: *const u8, n_jpegs: usize,
) -> CcBuf {
    let Some(h) = (unsafe { text(header_json) }).and_then(|t| serde_json::from_str::<HeaderIn>(t).ok()) else {
        return give(Vec::new());
    };
    let jpeg_bytes = unsafe { slice(jpegs, n_jpegs) };
    let mut at = 0usize;
    let mut keyframes = Vec::new();
    for k in h.keyframes {
        let (Ok(pose), Ok(intrinsics)) = (<[f32; 16]>::try_from(k.pose), <[f32; 9]>::try_from(k.intrinsics)) else {
            return give(Vec::new());
        };
        let Some(jpeg) = jpeg_bytes.get(at..at + k.jpeg_len) else { return give(Vec::new()) };
        at += k.jpeg_len;
        keyframes.push(Keyframe { pose, intrinsics, width: k.width, height: k.height, jpeg: jpeg.to_vec() });
    }
    let shot = Shot {
        header: h.header,
        positions: unsafe { slice(positions, n_positions) }.to_vec(),
        normals: unsafe { slice(normals, n_normals) }.to_vec(),
        indices: unsafe { slice(indices, n_indices) }.to_vec(),
        keyframes,
    };
    let bytes = encode(&shot);
    if decode(&bytes).is_err() { give(Vec::new()) } else { give(bytes) }
}

fn place(shot: &Shot, st: &[f64]) -> Option<cave_capture::Placement> {
    let tap = shot.header.taps.first()?;
    let station = Vec3 { x: st[0], y: st[1], z: st[2] };
    let target = Vec3 { x: st[3], y: st[4], z: st[5] };
    heading_from_tap(station, target, tap.dir, shot.header.start_camera, shot.header.instrument_height_m)
}

fn placed_points(shot: &Shot, st: &[f64]) -> Option<(Vec<Vec3>, f64)> {
    let p = place(shot, st)?;
    let pts = shot.positions.chunks_exact(3).map(|c| p.apply([c[0] as f64, c[1] as f64, c[2] as f64])).collect();
    Some((pts, p.turn_deg))
}

/// See `capture_core.h`.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn cc_shot_summary(bundle: *const u8, len: usize, station_and_target: *const f64) -> CcBuf {
    let shot = match decode(unsafe { slice(bundle, len) }) {
        Ok(s) => s,
        Err(e) => return err(&format!("{e:?}")),
    };
    let st = unsafe { slice(station_and_target, 6) };
    let mut out = serde_json::json!({
        "vertices": shot.positions.len() / 3,
        "triangles": shot.indices.len() / 3,
        "keyframes": shot.keyframes.len(),
        "placed": false,
    });
    if st.len() == 6 {
        if let Some((pts, turn)) = placed_points(&shot, st) {
            let mut min = [f64::INFINITY; 3];
            let mut max = [f64::NEG_INFINITY; 3];
            for q in &pts {
                for (i, v) in [q.x, q.y, q.z].into_iter().enumerate() {
                    min[i] = min[i].min(v);
                    max[i] = max[i].max(v);
                }
            }
            out["placed"] = true.into();
            out["min"] = serde_json::json!(min);
            out["max"] = serde_json::json!(max);
            out["turn_deg"] = turn.into();
        }
    }
    give_json(out)
}

/// See `capture_core.h`.
#[unsafe(no_mangle)]
pub unsafe extern "C" fn cc_shot_placed_positions(bundle: *const u8, len: usize, station_and_target: *const f64) -> CcBuf {
    let st = unsafe { slice(station_and_target, 6) };
    let Ok(shot) = decode(unsafe { slice(bundle, len) }) else { return give(Vec::new()) };
    if st.len() != 6 {
        return give(Vec::new());
    }
    let Some((pts, _)) = placed_points(&shot, st) else { return give(Vec::new()) };
    let mut out = Vec::with_capacity(pts.len() * 12);
    for q in pts {
        for v in [q.x as f32, q.y as f32, q.z as f32] {
            out.extend_from_slice(&v.to_le_bytes());
        }
    }
    give(out)
}
```

```swift
import Foundation
import Security

/// The sign-in token, kept in the Keychain (this device only).
enum Keychain {
    private static let service = "app.cavecad.capture.token"

    static func save(_ token: String) {
        delete()
        let q: [String: Any] = [kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: service,
                                kSecAttrAccessible as String: kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly,
                                kSecValueData as String: Data(token.utf8)]
        SecItemAdd(q as CFDictionary, nil)
    }

    static func load() -> String? {
        let q: [String: Any] = [kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: service,
                                kSecReturnData as String: true, kSecMatchLimit as String: kSecMatchLimitOne]
        var out: CFTypeRef?
        guard SecItemCopyMatching(q as CFDictionary, &out) == errSecSuccess, let d = out as? Data else { return nil }
        return String(data: d, encoding: .utf8)
    }

    static func delete() {
        SecItemDelete([kSecClass as String: kSecClassGenericPassword, kSecAttrService as String: service] as CFDictionary)
    }
}
```

```swift
import AuthenticationServices
import CryptoKit
import Foundation

enum PKCE {
    static func verifier() -> String {
        var bytes = [UInt8](repeating: 0, count: 32)
        _ = SecRandomCopyBytes(kSecRandomDefault, bytes.count, &bytes)
        return base64url(Data(bytes))
    }
    static func challenge(for verifier: String) -> String {
        base64url(Data(SHA256.hash(data: Data(verifier.utf8))))
    }
    static func base64url(_ d: Data) -> String {
        d.base64EncodedString().replacingOccurrences(of: "+", with: "-")
            .replacingOccurrences(of: "/", with: "_").replacingOccurrences(of: "=", with: "")
    }
}

/// The CaveCAD account: sign-in through cavecad.com (the desktop hand-off) and the bearer token.
@MainActor
final class Account: NSObject, ObservableObject, ASWebAuthenticationPresentationContextProviding {
    static let server = URL(string: Bundle.main.object(forInfoDictionaryKey: "CaveCADServer") as? String ?? "https://cavecad.com")!

    @Published private(set) var token: String? = Keychain.load()
    @Published private(set) var email: String?
    @Published var problem: String?

    static func signInURL(server: URL, challenge: String, state: String) -> URL {
        var c = URLComponents(url: server.appendingPathComponent("signin"), resolvingAgainstBaseURL: false)!
        c.queryItems = [.init(name: "desktop", value: "1"), .init(name: "challenge", value: challenge), .init(name: "state", value: state)]
        return c.url!
    }

    static func code(from callback: URL, state: String) -> String? {
        let q = URLComponents(url: callback, resolvingAgainstBaseURL: false)?.queryItems ?? []
        guard q.first(where: { $0.name == "state" })?.value == state else { return nil }
        return q.first(where: { $0.name == "code" })?.value
    }

    func signIn() {
        let verifier = PKCE.verifier(), state = PKCE.verifier()
        let url = Self.signInURL(server: Self.server, challenge: PKCE.challenge(for: verifier), state: state)
        let session = ASWebAuthenticationSession(url: url, callback: .customScheme("cavecad")) { [weak self] cb, error in
            Task { @MainActor in
                guard let self else { return }
                guard let cb, let code = Self.code(from: cb, state: state) else {
                    self.problem = error == nil ? "Sign-in did not finish." : nil
                    return
                }
                await self.redeem(code: code, verifier: verifier)
            }
        }
        session.presentationContextProvider = self
        session.prefersEphemeralWebBrowserSession = false
        session.start()
    }

    private func redeem(code: String, verifier: String) async {
        var req = URLRequest(url: Self.server.appendingPathComponent("api/desktop-token"))
        req.httpMethod = "POST"
        req.setValue("application/json", forHTTPHeaderField: "Content-Type")
        req.httpBody = try? JSONSerialization.data(withJSONObject: ["code": code, "verifier": verifier])
        do {
            let (data, resp) = try await URLSession.shared.data(for: req)
            guard (resp as? HTTPURLResponse)?.statusCode == 200,
                  let t = (try JSONSerialization.jsonObject(with: data) as? [String: Any])?["token"] as? String
            else { problem = "The server refused the sign-in."; return }
            Keychain.save(t)
            token = t
            await loadMe()
        } catch { problem = "No connection to CaveCAD." }
    }

    func loadMe() async {
        guard let data = try? await get("api/me"),
              let me = try? JSONSerialization.jsonObject(with: data) as? [String: Any] else { return }
        email = (me["member"] as? [String: Any])?["email"] as? String ?? me["email"] as? String
    }

    func signOut() { Keychain.delete(); token = nil; email = nil }

    /// An authenticated GET. Throws on no connection; a 401 signs out.
    func get(_ path: String, query: [URLQueryItem] = []) async throws -> Data {
        var c = URLComponents(url: Self.server.appendingPathComponent(path), resolvingAgainstBaseURL: false)!
        if !query.isEmpty { c.queryItems = query }
        var req = URLRequest(url: c.url!)
        req.setValue("Bearer \(token ?? "")", forHTTPHeaderField: "Authorization")
        let (data, resp) = try await URLSession.shared.data(for: req)
        if (resp as? HTTPURLResponse)?.statusCode == 401 { signOut() }
        return data
    }

    func authorized(_ url: URL) -> URLRequest {
        var req = URLRequest(url: url)
        req.setValue("Bearer \(token ?? "")", forHTTPHeaderField: "Authorization")
        return req
    }

    nonisolated func presentationAnchor(for session: ASWebAuthenticationSession) -> ASPresentationAnchor {
        MainActor.assumeIsolated {
            UIApplication.shared.connectedScenes.compactMap { ($0 as? UIWindowScene)?.keyWindow }.first ?? ASPresentationAnchor()
        }
    }
}
```

```swift
struct Station: Codable, Hashable, Identifiable {

    let label: String

struct CoreError: Error, LocalizedError { let message: String; var errorDescription: String? { message } }

/// Swift face of the Rust core (`capture_core.h`). Every buffer is copied out and freed here.
enum Core {
    private static func take(_ b: CcBuf) -> Data {
        defer { cc_free(b) }
        guard let p = b.ptr, b.len > 0 else { return Data() }
        return Data(bytes: p, count: b.len)
    }

    static func stations(snapshot: String?, entries: [String]) throws -> [Station] {
        let entriesJSON = String(data: try JSONSerialization.data(withJSONObject: entries), encoding: .utf8)!
        let data: Data = entriesJSON.withCString { e in
            if let snapshot { return snapshot.withCString { s in take(cc_stations(s, e)) } }
            return take(cc_stations(nil, e))
        }
        if let obj = try? JSONSerialization.jsonObject(with: data) as? [String: Any], let m = obj["error"] as? String {
            throw CoreError(message: m)
        }
        return try JSONDecoder().decode([Station].self, from: data)
    }

    /// Station and target as six doubles for the placement calls.
    static func pair(_ over: Station, _ forward: Station) -> [Double] {
        [over.x, over.y, over.z, forward.x, forward.y, forward.z]
    }

    static func encodeShot(header: Data, positions: [Float], normals: [Float], indices: [UInt32], jpegs: Data) -> Data {
        let h = String(data: header, encoding: .utf8)!
        return h.withCString { hp in
            positions.withUnsafeBufferPointer { p in normals.withUnsafeBufferPointer { n in
                indices.withUnsafeBufferPointer { i in jpegs.withUnsafeBytes { j in
                    take(cc_shot_encode(hp, p.baseAddress, p.count, n.baseAddress, n.count, i.baseAddress, i.count,
                                        j.bindMemory(to: UInt8.self).baseAddress, j.count))
                } }
            } }
        }
    }

    static func summary(bundle: Data, pair: [Double]) -> [String: Any] {
        let d = bundle.withUnsafeBytes { b in pair.withUnsafeBufferPointer { s in
            take(cc_shot_summary(b.bindMemory(to: UInt8.self).baseAddress, b.count, s.baseAddress))
        } }
        return (try? JSONSerialization.jsonObject(with: d) as? [String: Any]) ?? ["error": "unreadable"]

    static func placedPositions(bundle: Data, pair: [Double]) -> [Float] {

            take(cc_shot_placed_positions(b.bindMemory(to: UInt8.self).baseAddress, b.count, s.baseAddress))
```

```swift
import Foundation

struct CaveInfo: Codable, Identifiable, Hashable { let id: String; let name: String }

/// A downloaded cave, kept on the phone for use underground.
struct KeptCave: Codable {
    let id: String
    let name: String
    let snapshot: String?
    let entries: [String]
    let last: Int
    let keptAt: Date
}

@MainActor
final class CaveStore: ObservableObject {
    @Published var caves: [CaveInfo] = []
    @Published var offline = false
    @Published var problem: String?
    private let account: Account

    init(account: Account) { self.account = account }

    static var folder: URL {
        let u = FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0].appendingPathComponent("caves")
        try? FileManager.default.createDirectory(at: u, withIntermediateDirectories: true)
        return u
    }

    static func parseStream(_ body: String) -> (entries: [String], last: Int, caughtUp: Bool) {
        var entries: [String] = [], last = 0, live = false
        for line in body.split(separator: "\n") where !live {
            guard let o = try? JSONSerialization.jsonObject(with: Data(line.utf8)) as? [String: Any] else { continue }
            switch o["t"] as? String {
            case "entry": if let t = o["locked"] as? String { entries.append(t); last = o["number"] as? Int ?? last }
            case "live": live = true
            default: break
            }
        }
        return (entries, last, live)
    }

    func kept() -> [KeptCave] {
        let files = (try? FileManager.default.contentsOfDirectory(at: Self.folder, includingPropertiesForKeys: nil)) ?? []
        return files.compactMap { try? JSONDecoder().decode(KeptCave.self, from: Data(contentsOf: $0)) }
    }

    func refresh() async {
        do {
            let data = try await account.get("api/caves")
            let list = (try JSONSerialization.jsonObject(with: data) as? [String: Any])?["caves"] as? [[String: Any]] ?? []
            caves = list.compactMap { c in
                guard let id = c["id"] as? String else { return nil }
                return CaveInfo(id: id, name: (c["name"] as? String) ?? (c["label"] as? [String: Any])?["name"] as? String ?? id)
            }
            offline = false
        } catch {
            offline = true
            caves = kept().map { CaveInfo(id: $0.id, name: $0.name) }
        }
    }

    /// Downloads a cave (snapshot, then every entry until the stream says it is live) and keeps it.
    func download(_ cave: CaveInfo) async throws -> KeptCave {
        let snapData = try await account.get("api/caves/\(cave.id)/snapshot")
        let snap = (try JSONSerialization.jsonObject(with: snapData) as? [String: Any])?["snapshot"] as? [String: Any]
        let snapshot = snap?["locked"] as? String
        let after = snap?["upTo"] as? Int ?? 0
        var req = account.authorized(Account.server.appendingPathComponent("api/caves/\(cave.id)/stream"))
        req.url = URL(string: req.url!.absoluteString + "?after=\(after)")
        let (bytes, _) = try await URLSession.shared.bytes(for: req)
        var body = ""
        for try await line in bytes.lines {
            body += line + "\n"
            if line.contains(#""t":"live""#) { break }
        }
        let parsed = Self.parseStream(body)
        let k = KeptCave(id: cave.id, name: cave.name, snapshot: snapshot, entries: parsed.entries,
                         last: max(after, parsed.last), keptAt: Date())
        try JSONEncoder().encode(k).write(to: Self.folder.appendingPathComponent("\(cave.id).json"), options: .atomic)
        return k
    }

    func load(_ id: String) -> KeptCave? {
        try? JSONDecoder().decode(KeptCave.self, from: Data(contentsOf: Self.folder.appendingPathComponent("\(id).json")))
    }
}
```

```swift
import ARKit
import Foundation
import simd
import UIKit

/// One anchor's mesh, pulled out of ARKit so merging can be tested without a device.
struct MeshPart {
    var positions: [SIMD3<Float>]
    var normals: [SIMD3<Float>]
    var indices: [UInt32]
    var transform: simd_float4x4
}

struct MergedMesh { var positions: [Float]; var normals: [Float]; var indices: [UInt32] }

/// Runs one shot: ARKit scene reconstruction, heading tap, keyframes; turns it into a bundle on Stop.
@MainActor
final class ShotRecorder: NSObject, ObservableObject, ARSessionDelegate {
    enum Phase { case aiming, capturing, saving, saved(URL), failed(String) }

    @Published var phase: Phase = .aiming
    @Published var message = "Put the crosshair on the forward station and tap Aim."
    @Published var tapped = false
    @Published var keyframeCount = 0

    let session = ARSession()
    private var tap: (origin: SIMD3<Float>, dir: SIMD3<Float>)?
    private var startCamera = SIMD3<Float>(0, 0, 0)
    private var keyframes: [(pose: simd_float4x4, intrinsics: simd_float3x3, w: Int, h: Int, jpeg: Data)] = []
    private var lastYaw: Float = .nan, lastTime: TimeInterval = 0
    private var worstTracking = "normal"
    private let context = CIContext()

    static func shouldKeep(lastYaw: Float, yaw: Float, lastTime: TimeInterval, time: TimeInterval) -> Bool {
        if time - lastTime < 0.25 { return false }
        if lastYaw.isNaN { return true }
        var d = abs(yaw - lastYaw).truncatingRemainder(dividingBy: 360)
        if d > 180 { d = 360 - d }
        return d >= 15 || time - lastTime >= 2
    }

    static func mergeAnchors(_ parts: [MeshPart]) -> MergedMesh {
        var out = MergedMesh(positions: [], normals: [], indices: [])
        for p in parts {
            let base = UInt32(out.positions.count / 3)
            let rot = simd_float3x3(SIMD3(p.transform.columns.0.x, p.transform.columns.0.y, p.transform.columns.0.z),
                                    SIMD3(p.transform.columns.1.x, p.transform.columns.1.y, p.transform.columns.1.z),
                                    SIMD3(p.transform.columns.2.x, p.transform.columns.2.y, p.transform.columns.2.z))
            for v in p.positions {
                let w = p.transform * SIMD4(v, 1)
                out.positions += [w.x, w.y, w.z]
            }
            for n in p.normals {
                let w = simd_normalize(rot * n)
                out.normals += [w.x, w.y, w.z]
            }
            out.indices += p.indices.map { $0 + base }
        }
        return out
    }

    func run() {
        let c = ARWorldTrackingConfiguration()
        c.sceneReconstruction = .mesh
        c.frameSemantics = [.sceneDepth]
        c.isLightEstimationEnabled = true
        c.worldAlignment = .gravity
        session.delegate = self
        session.run(c, options: [.resetTracking, .removeExistingAnchors])
    }

    func aim() {
        guard let f = session.currentFrame else { return }
        let t = f.camera.transform
        let origin = SIMD3(t.columns.3.x, t.columns.3.y, t.columns.3.z)
        let fwd = -SIMD3(t.columns.2.x, t.columns.2.y, t.columns.2.z)
        tap = (origin, simd_normalize(fwd))
        tapped = true
        message = "Aimed. Press Start and turn slowly around the room."
    }

    func start() {
        guard let f = session.currentFrame else { return }
        if (f.lightEstimate?.ambientIntensity ?? 0) < 150 { message = "Too dark to track. Turn the light on."; return }
        guard case .normal = f.camera.trackingState else { message = "Hold still until tracking settles."; return }
        guard tapped else { message = "Aim at the forward station first."; return }
        let t = f.camera.transform
        startCamera = SIMD3(t.columns.3.x, t.columns.3.y, t.columns.3.z)
        keyframes = []; keyframeCount = 0; lastYaw = .nan; worstTracking = "normal"
        phase = .capturing
        message = "Capturing. Turn slowly; Stop when the room is covered."
    }

    nonisolated func session(_ session: ARSession, didUpdate frame: ARFrame) {
        let pose = frame.camera.transform
        let yaw = atan2(-pose.columns.2.x, -pose.columns.2.z) * 180 / .pi
        let time = frame.timestamp
        let state = frame.camera.trackingState
        let image = frame.capturedImage
        let intrinsics = frame.camera.intrinsics
        MainActor.assumeIsolated {
            guard case .capturing = phase else { return }
            switch state {
            case .normal: break
            case .notAvailable: worstTracking = "lost"
            case .limited: if worstTracking == "normal" { worstTracking = "limited" }
            }
            guard Self.shouldKeep(lastYaw: lastYaw, yaw: yaw, lastTime: lastTime, time: time) else { return }
            let ci = CIImage(cvPixelBuffer: image)
            guard let jpeg = context.jpegRepresentation(of: ci, colorSpace: CGColorSpace(name: CGColorSpace.sRGB)!,
                                                        options: [kCGImageDestinationLossyCompressionQuality as CIImageRepresentationOption: 0.7])
            else { return }
            keyframes.append((pose, intrinsics, CVPixelBufferGetWidth(image), CVPixelBufferGetHeight(image), jpeg))
            keyframeCount = keyframes.count
            lastYaw = yaw; lastTime = time
        }
    }

    func stop(cave: KeptCave, over: Station, forward: Station) {
        guard case .capturing = phase, let tap else { return }
        phase = .saving
        let anchors = session.currentFrame?.anchors.compactMap { $0 as? ARMeshAnchor } ?? []
        session.pause()
        let parts = anchors.map(Self.part)
        let mesh = Self.mergeAnchors(parts)
        let shotId = UUID().uuidString.lowercased()
        var jpegs = Data()
        var kfs: [[String: Any]] = []
        for k in keyframes {
            jpegs.append(k.jpeg)
            let p = k.pose, i = k.intrinsics
            kfs.append(["pose": [p.columns.0, p.columns.1, p.columns.2, p.columns.3].flatMap { [$0.x, $0.y, $0.z, $0.w] },
                        "intrinsics": [i.columns.0, i.columns.1, i.columns.2].flatMap { [$0.x, $0.y, $0.z] },
                        "width": k.w, "height": k.h, "jpeg_len": k.jpeg.count])
        }
        let header: [String: Any] = [
            "shot_id": shotId, "cave_id": cave.id, "station_id": over.id, "station_label": over.label,
            "captured_at_ms": Int64(Date().timeIntervalSince1970 * 1000), "device": Self.model(),
            "instrument_height_m": 0.0, "start_camera": [startCamera.x, startCamera.y, startCamera.z].map(Double.init),
            "taps": [["target_station_id": forward.id, "target_label": forward.label,
                      "origin": [tap.origin.x, tap.origin.y, tap.origin.z].map(Double.init),
                      "dir": [tap.dir.x, tap.dir.y, tap.dir.z].map(Double.init)]],
            "tracking": worstTracking, "keyframes": kfs,
        ]
        let bundle = Core.encodeShot(header: try! JSONSerialization.data(withJSONObject: header),
                                     positions: mesh.positions, normals: mesh.normals, indices: mesh.indices, jpegs: jpegs)
        guard !bundle.isEmpty else { phase = .failed("The shot could not be written."); return }
        do { phase = .saved(try ShotFiles.save(bundle, cave: cave.id, shot: shotId)) }
        catch { phase = .failed("Saving failed: \(error.localizedDescription)") }
    }

    private static func part(_ a: ARMeshAnchor) -> MeshPart {
        let g = a.geometry
        func vec3(_ s: ARGeometrySource) -> [SIMD3<Float>] {
            (0..<s.count).map { i in
                let p = s.buffer.contents().advanced(by: s.offset + s.stride * i).assumingMemoryBound(to: Float.self)
                return SIMD3(p[0], p[1], p[2])
            }
        }
        let f = g.faces
        let idx = UnsafeBufferPointer(start: f.buffer.contents().assumingMemoryBound(to: UInt32.self), count: f.count * 3)
        return MeshPart(positions: vec3(g.vertices), normals: vec3(g.normals), indices: Array(idx), transform: a.transform)
    }

    private static func model() -> String {
        var s = utsname(); uname(&s)
        return withUnsafeBytes(of: s.machine) { String(cString: $0.bindMemory(to: CChar.self).baseAddress!) }
    }
}
```

```swift
import Foundation

/// Shots kept on the phone: Documents/shots/<caveId>/<shotId>.cvcap.
enum ShotFiles {
    static func folder(cave: String) -> URL {
        let u = FileManager.default.urls(for: .documentDirectory, in: .userDomainMask)[0]
            .appendingPathComponent("shots").appendingPathComponent(cave)
        try? FileManager.default.createDirectory(at: u, withIntermediateDirectories: true)
        return u
    }
    static func save(_ bundle: Data, cave: String, shot: String) throws -> URL {
        let u = folder(cave: cave).appendingPathComponent("\(shot).cvcap")
        try bundle.write(to: u, options: [.atomic, .completeFileProtectionUntilFirstUserAuthentication])
        return u
    }
    static func list(cave: String) -> [URL] {
        ((try? FileManager.default.contentsOfDirectory(at: folder(cave: cave), includingPropertiesForKeys: [.creationDateKey])) ?? [])
            .filter { $0.pathExtension == "cvcap" }.sorted { $0.lastPathComponent < $1.lastPathComponent }
    }
}
```

```swift
import SceneKit
import SwiftUI

struct ShotView: View {
    let url: URL; let over: Station; let forward: Station
    @State private var summary: [String: Any] = [:]
    @State private var scene: SCNScene?

    var body: some View {
        VStack(spacing: 0) {
            if let scene {
                SceneView(scene: scene, options: [.allowsCameraControl, .autoenablesDefaultLighting]).frame(maxHeight: .infinity)
            } else if summary["placed"] as? Bool == false {
                Text("Not placed: aim again (the tap had no direction).").padding()
            }
            HStack {
                Text("\(summary["vertices"] as? Int ?? 0) points")
                Text("\(summary["triangles"] as? Int ?? 0) triangles")
                Text("\(summary["keyframes"] as? Int ?? 0) photos")
                if let t = summary["turn_deg"] as? Double { Text(String(format: "turned %.1f°", t)) }
            }.font(.caption).padding(8)
        }
        .navigationTitle(over.label)
        .task {
            guard let data = try? Data(contentsOf: url) else { return }
            let pair = Core.pair(over, forward)
            summary = Core.summary(bundle: data, pair: pair)
            guard summary["placed"] as? Bool == true else { return }
            scene = Self.scene(points: Core.placedPositions(bundle: data, pair: pair), over: over, forward: forward)
        }
    }

    /// Survey (x east, y north, z up) shown in SceneKit (y up): (x, z, -y).
    static func scene(points: [Float], over: Station, forward: Station) -> SCNScene {
        let s = SCNScene()
        var verts: [SCNVector3] = []
        verts.reserveCapacity(points.count / 3)
        var i = 0
        while i + 2 < points.count { verts.append(SCNVector3(points[i], points[i + 2], -points[i + 1])); i += 3 }
        let src = SCNGeometrySource(vertices: verts)
        let el = SCNGeometryElement(indices: Array(0..<Int32(verts.count)), primitiveType: .point)
        el.pointSize = 2; el.minimumPointScreenSpaceRadius = 1; el.maximumPointScreenSpaceRadius = 3
        let g = SCNGeometry(sources: [src], elements: [el])
        g.firstMaterial?.diffuse.contents = UIColor.systemGray
        g.firstMaterial?.lightingModel = .constant
        s.rootNode.addChildNode(SCNNode(geometry: g))
        for (st, colour) in [(over, UIColor.systemRed), (forward, UIColor.systemBlue)] {
            let n = SCNNode(geometry: SCNSphere(radius: 0.1))
            n.geometry?.firstMaterial?.diffuse.contents = colour
            n.position = SCNVector3(Float(st.x), Float(st.z), Float(-st.y))
            s.rootNode.addChildNode(n)
        }
        return s
    }
}
```
