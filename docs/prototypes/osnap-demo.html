Object snap demo (2D top view)

  • Click to draw a wall. Enter or double-click ends it. Drawn walls become snappable.
  • Shift+right-click (or Ctrl+right-click, or long-press) opens the one-pick override menu. The next click uses only that snap. A miss does nothing.
  • F3 running snaps. F10 tracking (polar + hover-acquire). Tab cycles candidates.
  • Extension: turn it on (running or override), hover a line/arc/spline end ~0.3 s: a + appears and a dotted line runs on. Hover two ends to snap to where they cross.
  • Temporary Track Point: menu, then click a point (snaps), then move along the guides. Chain more from the menu.
  • Parallel: draw a first point, enable Parallel, hover a line ~0.3 s.
  • With a guide locked, type a number then Enter for an exact distance. From: pick base, type dx,dy.
  • Plain right-click or Esc cancels. Backspace removes the last point. Wheel zooms, Space+drag or middle-drag pans.
  • Real engine does this in Rust through the 3D camera; this page only tests the feel.
